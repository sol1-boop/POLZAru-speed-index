**Инструкция по использованию телеграм-бота:**
/audit_mobile
Для разовой проверки доменов из domains.json

/start_track
Для мониторинга из domains.json через заданные промежутки времени (один раз в 2 ч. по умолчанию)

/stop_track
Оставить мониторинг

/stats
Получение статистики в канал измерений из файлов типа %example.ru%.json
